基础体征 体表面积 (BSA) - 许文生中国人群公式 & DuBois公式
📚 人卫第10版《儿科学》P45、《外科学》P129
内科/代谢 校正血钙 (Corrected Calcium)
📚 人卫第10版《内科学》P801
📖 临床案例演示
患者：男性，55kg，慢性肾功能不全伴低白蛋白血症，实测血钙 1.9mmol/L，血清白蛋白 25g/L，无明显手足搐搦。
计算：校正血钙=1.9+0.02×(40−25)=1.9+0.3=2.2mmol/L（低钙血症边界，低于2.25为偏低）。
执行：急性症状性低钙（手足搐搦/喉痉挛）：10%葡萄糖酸钙 10-20ml 以 5%GS 等量稀释后缓慢静注/静滴（约10min），心电监护；慢性低钙：口服钙剂（碳酸钙）+活性维生素D，同时查血镁，合并低镁需同时纠正。动态监测血钙、白蛋白与心电图。
水电解质 阴离子隙 (AG) 与缺钠/补钠量计算器
📚 人卫第10版《内科学》P789-792
📖 临床案例演示
患者：女性，50kg，慢性腹泻后乏力头晕，血钠128mmol/L、血氯95mmol/L、HCO₃20mmol/L。
计算：AG=128−(95+20)=13mmol/L（正常范围）；缺钠量=(142−128)×50×0.5=350mmol；相当于0.9%NS≈350/0.154≈2273ml 或 3%高渗盐水≈350/0.513≈682ml。
执行：首日补缺钠量1/2（175mmol）+每日生理需要量；慢性低钠纠正速度宜缓：血钠24h升高一般≤8-10mmol/L（前24h不超过10），防渗透性脱髓鞘综合征；每4-6h复查血钠；症状性重度低钠（血钠<120或伴抽搐/昏迷）可考虑3%高渗盐水并严密监测。能口服者口服补钠/ORS优先。
水电解质 成人等渗性脱水补液量计算器
📚 人卫第10版《外科学》水、电解质代谢紊乱
🧪 所用液体与补液方法
【所用液体】轻度：口服补液盐(ORS)、平衡液(乳酸/醋酸林格)、0.9%氯化钠；中重度：首日含钠液为主，0.9%NS:5%GS≈2:1，可配平衡液。
【补液方法】途径：轻中度可口服/静脉，重度静脉滴注。分配：首日先补累计失液量1/2（前6-8h较快输入），余1/2+生理需要量2000ml+持续丢失量24h内匀速补充。速度：成人初始200-300ml/h（心衰/老年减量）。见尿补钾（尿量≥40ml/h后加钾）。监测：尿量、生命体征、CVP、血电解质。
📖 临床案例演示
患者：男性，60kg，急性肠梗阻伴频繁呕吐2天，中度脱水（约5%），无额外持续丢失。
计算：累计失液量=60×5%×1000=3000ml；首日补1/2=1500ml；+成人日生理需要量2000ml；当日补液总量=1500+2000=3500ml。
执行：先盐后糖原则，前6-8h较快输入1500ml含钠液（0.9%NS:5%GS≈2:1），余量24h内匀速；尿量≥40ml/h后见尿补钾；动态监测尿量、血电解质与生命体征。
水电解质 每日生理需要量（维持液）计算器
📚 《中国临床液体治疗专家共识》/ 人卫《外科学》
🧪 所用液体与补液方法
【所用液体】5%GS或10%GS（基础糖液）+0.9%NS或5%葡萄糖氯化钠+10%KCl（浓度≤0.3%）；也可用复方氯化钠。
【补液方法】禁食者静脉滴注、24h匀速；能进食者口服为主。配比示例：按日需氯化钠 4-6g、K 3-4g → 0.9%NS 500ml（含NaCl约4.5g）+5%GS 1000ml+10%KCl 30ml（约3g）分瓶滴注。速度约80-120ml/h（视总量）。监测出入量、尿量、电解质；糖尿病者注意含糖液血糖监测。
📖 临床案例演示
患者：女性，60kg，腹腔镜胆囊切除术后禁食第1天，需静脉维持补液。
计算：成人法=60×35=2100ml/日（约87.5ml/h）；4-2-1法=60+1×(60-20)=100ml/h→2400ml/日。
执行：0.9%NS 500ml+5%GS 1000ml+10%KCl 30ml（浓度≤0.3%）分瓶滴注，24h匀速约87-100ml/h；记录出入量、复查电解质与血糖。
水电解质 高渗性脱水/高钠血症自由水缺乏量计算器
📚 人卫第10版《内科学》高钠血症 / 《哈里森内科学》
🧪 所用液体与补液方法
【所用液体】5%GS（纯自由水、无电解质）或0.45%氯化钠（半张）；能口服者凉开水/白开水。
【补液方法】轻症口服，重症静脉。速度控制使血钠每小时下降≤0.5-1mmol/L、24h下降≤10mmol/L（防渗透性脱髓鞘）。先补计算缺乏量的1/2，分次补充并计入每日生理需要量，可2-3日逐渐纠正。每2-4h复查血钠。
📖 临床案例演示
患者：男性，60kg，意识障碍伴明显口渴，血钠155mmol/L，高渗性脱水。
计算：自由水缺乏量=0.6×60×(1−140/155)≈3.48L；累计缺水量≈3480ml。
执行：首日补1/2约1.7L自由水（5%GS或0.45%NS半张盐），使血钠每小时下降≤0.5-1mmol/L、24h≤10mmol/L，2-3日逐渐纠正；每2-4h复查血钠，防渗透性脱髓鞘综合征。
酸碱平衡 代谢性酸中毒补碱量（碳酸氢钠）计算器
📚 《内科学》酸碱平衡 / 临床补碱原则
🧪 所用液体与补液方法
【所用液体】5%碳酸氢钠注射液(250ml/瓶)；需缓慢可稀释为1.4%等渗碳酸氢钠（5%液1份+5%GS或灭菌注射用水2.5份）。
【补液方法】静脉滴注。先补计算量1/2（30-60min内），复测血气再决定余量。速度不宜过快（成人5%NaHCO3一般≤200ml/h，或1-2ml/kg/h），防高钠、容量超负荷、渗透压骤升。指征：pH<7.2的重度酸中毒；轻中度代酸以治疗原发病为主。注意补碱致低钾，须监测并酌情补钾。
📖 临床案例演示
患者：男性，60kg，糖尿病酮症酸中毒，血气BE=−10mmol/L、pH 7.15。
计算：补碱量=10×0.3×60=180mmol；5%NaHCO3=180/0.6=300ml（约1.2瓶/250ml，临床按整瓶取用约需2瓶）。
执行：DKA应以补液+小剂量胰岛素治疗为主，仅当pH<7.1才考虑静脉补碱；若确需补碱则先补计算量1/2（90mmol≈150ml 5%NaHCO3，30-60min内），复测血气再定余量；注意补碱致低钾，需监测血钾并酌情补钾。
电解质 低钾血症补钾量计算器
📚 《内科学》低钾血症 / 临床补钾规范
🧪 所用液体与补液方法
【所用液体】口服：10%氯化钾口服液/氯化钾缓释片/枸橼酸钾颗粒；静脉：10%氯化钾注射液(10ml:1g)。
【补液方法】能口服者口服优先（更安全）。静脉配液浓度≤0.3%（1000ml液体中≤30ml 10%KCl），中心静脉可≤0.6%；外周滴速≤10-20mmol/h；每日总量≤3-6g(40-80mmol)。先补1/2复查；见尿补钾(尿量>30ml/h)；心电监护（血钾<2.5或伴心律失常考虑深静脉途径）。
📖 临床案例演示
患者：女性，50kg，长期服用噻嗪类利尿剂，血钾3.0mmol/L，感乏力。
计算：缺钾量=(4.0−3.0)×50×0.3=15mmol；10%KCl=15/1.34≈11ml。
执行：能口服者口服补钾优先（10%KCl口服液分次口服）；静脉则0.9%NS 500ml+10%KCl≤15ml（浓度≤0.3%）缓慢滴注，滴速≤10-20mmol/h；先补1/2复查；见尿补钾（尿量>30ml/h）；心电监护。
电解质 低镁血症补镁量计算器
📚 《内科学》电解质紊乱 / 临床补镁规范
🧪 所用液体与补液方法
【所用液体】25%硫酸镁注射液(10ml:2.5g，1ml≈1mmol Mg²⁺)、10%硫酸镁、口服门冬氨酸钾镁/氧化镁/乳酸镁。
【补液方法】轻中度：每日 25%硫酸镁 10-20ml 加入液体（5%GS/0.9%NS 250-500ml）缓慢静滴，分 1-2 次；重度：20-40ml 分次静滴，症状性先 10-20ml 稀释后 10-20min 缓慢静注；监测膝腱反射、呼吸、血压；肾功能不全减量或慎用；静注过快可致低血压甚至心脏骤停。
📖 临床案例演示
患者：男性，60kg，慢性酒精性肝病、长期进食差，血镁0.45mmol/L，伴手颤。
计算：细胞外缺镁估算=(0.8−0.45)×60×0.3≈6.3mmol（仅供参考，血镁仅反映约1%总镁）；临床按重度低镁每日补25%硫酸镁20-40ml（20-40mmol）分次静滴，症状性首剂20ml稀释后10-20min缓慢静注。
执行：25%硫酸镁20ml加入5%GS 500ml缓慢静滴（4-6h）；监测膝腱反射、呼吸与血压；肾功能不全减量；与洋地黄合用慎用；病情稳定后口服门冬氨酸钾镁维持。
电解质 低磷血症补磷量计算器
📚 《内科学》电解质紊乱 / 临床补磷规范
🧪 所用液体与补液方法
【所用液体】甘油磷酸钠注射液（10ml:2.16g，1ml≈1mmol磷，10ml/支）；口服磷酸盐（磷酸二氢钠/磷酸钾）；补磷常同时补充镁钾。
【补液方法】轻中度口服磷酸盐；重度（血磷<0.3）静脉补磷 0.2-0.5 mmol/kg/日（甘油磷酸钠 10-20ml/日加入液体缓慢静滴）；补磷过快致低钙抽搐，需监测血磷血钙；低磷常伴低镁低钾应同时纠正。
📖 临床案例演示
患者：女性，55kg，慢性酒精戒断+呼吸性碱中毒，血磷0.2mmol/L（重度低磷），伴明显乏力与呼吸困难。
计算：缺磷量=(1.0−0.2)×55×0.5≈22mmol；甘油磷酸钠≈22ml（约3支/10ml）。
执行：重度低磷（<0.3）需静脉补磷0.2-0.5mmol/kg/日（本例11-28mmol/日），甘油磷酸钠10-20ml加入0.9%NS 500ml缓慢静滴；监测血磷/血钙（防低钙抽搐）；同时查血镁血钾并纠正；病情稳定后改口服磷酸盐维持。
